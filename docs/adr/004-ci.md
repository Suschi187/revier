# ADR 004: CI-Grundlage

Status: angenommen (M0)

## Kontext
Die Definition of Done verlangt grüne Lint-, Typecheck- und Testläufe. Remote ist ein privates GitHub-Repo.

## Entscheidung
- GitHub Actions, Workflow `web.yml`, läuft auf Push und Pull Request bei Änderungen unter `web/`: `npm ci`, lint, typecheck, test, build.
- Ohne Secrets und ohne Deploy.
- Ein Secret-Guard schlägt fehl, wenn `NEXT_PUBLIC_*SERVICE*` im Code vorkommt.

## Alternativen
iOS-CI (macOS-Runner) und Migrations-CI bleiben vorerst außen vor. iOS-CI wird ab I1, Migrations-CI ab M1 geprüft.

## Folgen
Deploy-Pipelines kommen erst mit der Hosting-Entscheidung (SPEC 7.9).
