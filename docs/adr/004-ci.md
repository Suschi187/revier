# ADR 004: CI-Grundlage

Status: angenommen (M0)

## Kontext
Die Definition of Done verlangt grüne Lint-, Typecheck- und Testläufe. Remote ist ein privates GitHub-Repo.

## Entscheidung
- GitHub Actions, Workflow `web.yml`, läuft bei jedem Push auf `main` und jedem Pull Request (ohne Pfadfilter, damit der Secret-Guard das ganze Repo prüft): `npm ci`, lint, typecheck, test, build. `.next/cache` wird zwischen Läufen gecacht.
- Ohne Secrets und ohne Deploy.
- Ein Secret-Guard schlägt fehl, wenn `NEXT_PUBLIC_*SERVICE*`/`*SECRET*`, ein Supabase-Secret-Key (`sb_secret_…`) oder ein privater Schlüssel im Repo vorkommt. Ein vollständiger Scanner (z. B. gitleaks) wäre eine neue Abhängigkeit und wird bei Bedarf per ADR ergänzt.
- npm 11 meldet nicht ausgeführte install-scripts (`unrs-resolver`, `@parcel/watcher`, `@swc/core`). Sie bleiben bewusst deaktiviert: Lint, Typecheck, Tests und Build laufen ohne sie. Eine Freigabe wird nur erteilt, wenn ein Werkzeug sie nachweislich braucht.

## Alternativen
iOS-CI (macOS-Runner) bleibt vorerst außen vor und wird ab I1 geprüft. Migrationen und RLS-Tests laufen ab M1 im eigenen Workflow `supabase.yml` (ADR 009).

## Folgen
Deploy-Pipelines kommen erst mit der Hosting-Entscheidung (SPEC 7.9).
